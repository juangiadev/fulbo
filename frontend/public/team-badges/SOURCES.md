# Team badge assets

These local PNG files keep favorite-team badges independent of a third-party image host. Argentine roster coverage is Primera División (30 clubs) and Primera Nacional (36 clubs), using the verified 2026 roster.

## Source methodology

New artwork was downloaded from the rendered thumbnail URLs exposed by the relevant Spanish Wikipedia article infobox or Wikimedia Commons file page. SVG artwork therefore uses Wikimedia’s rendered PNG thumbnail; original PNG artwork is stored as PNG. The source article/file names below identify every local asset. Club badges may be trademarks; keep usage aligned with the app’s product/legal requirements.
